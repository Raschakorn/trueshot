# TrueShot - Prototype for Distinguishing AI-Generated Images from Photographs

## Abstract

TrueShot is a prototype tool that estimates the probability that an image was generated by an artificial intelligence model rather than captured by a camera. It combines metadata analysis and pixel-level forensic methods and presents the evidence supporting its estimate. The current implementation is experimental and has not been validated on standard benchmark datasets.

## Methods

### 1. Metadata and Provenance Analysis

- Reads EXIF metadata and PNG textual chunks.
- Searches for AI-related keywords in file metadata, for example `Stable Diffusion`, `Midjourney`, or `DALL-E`.
- Searches for the strings `C2PA` and `JUMBF` in the file. This is a string search only. Cryptographic verification of C2PA signatures is not performed.
- Searches for the string `SynthID`. Watermark decoding is not performed.

### 2. Pixel-Level Forensic Analysis

- **Error Level Analysis (ELA):** Recompresses the image at JPEG quality 90 and visualizes the pixel-wise difference. Regions with higher difference may indicate editing or resynthesis.
- **Frequency Domain Analysis:** Applies a two-dimensional Fast Fourier Transform (FFT) and measures central spectral concentration. Some synthetic images show atypical spectral patterns.
- **Noise Residual:** Computes the residual between the image and a Gaussian-blurred version. Natural photographs typically show a more uniform noise distribution.
- **Laplacian Variance:** Measures image smoothness. Unusually low variance is treated as weak evidence for synthetic content.

Photo-Response Non-Uniformity (PRNU) analysis is not implemented in this version, as it requires multiple images from the same sensor for comparison.

### 3. Semantic Check (Preliminary)

- Face detection using a Haar cascade classifier. If a face is detected, manual inspection of eyes, teeth, and hands is recommended.
- Optical Character Recognition (OCR) for Thai text is not implemented. This is listed as future work.

### 4. Scoring

Scores from metadata and pixel-level analysis are combined using a fixed weighted average to produce a final probability estimate. This is a heuristic combination. It is not an ensemble of trained deep learning models. Models such as `umm-maybe`, `Organika/sdxl-detector`, and `DINOv2` are not loaded in this version.

## Implementation

```bash
pip install streamlit pillow numpy opencv-python-headless
streamlit run app_v3.py
```

Dependencies: Streamlit, Pillow, NumPy, OpenCV (headless).

## Limitations

- No method is perfect at distinguishing AI-generated images from photographs.
- The prototype has been tested only on a small set of informal examples. It has not been evaluated on GenImage, CIFAKE, or other benchmark datasets.
- Scores are heuristic and have not been calibrated.
- Detection performance may degrade as generative models improve.
- Results should not be used as sole evidence for classification or attribution.

## Future Work

- Evaluation on GenImage and CIFAKE with reported accuracy, precision, recall, and F1-score.
- Benchmark comparison with existing detectors.
- Implementation of Thai OCR using EasyOCR.
- Cryptographic verification of C2PA manifests.
- Integration of a trained ensemble classifier.
- API and browser extension.

## Reproducibility

All scoring thresholds are defined in `app_v3.py`. No external model weights are required for the current version.
